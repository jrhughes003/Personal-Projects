# Portfolio Website

A responsive, single-page portfolio with sections for projects, skills, experience, and contact info.

**Tech:** HTML, CSS, vanilla JavaScript

## Features

- Mobile-friendly hamburger navigation
- Project showcase cards and experience timeline
- Smooth scrolling and scroll-triggered animations
- Social media links

## Running locally

No build step — open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page markup |
| `styles.css` | Styles and responsive layout |
| `script.js` | Navigation and animations |
| `CUSTOMIZATION_GUIDE.md` | How to fill in your own content |
| `DEPLOYMENT_GUIDE.md` | Publishing to GitHub Pages and other hosts |
